# Custom Server Links! 

With this plugin, you're allowed to customize the "server links" menu button by adding you own things. 

It opens a dialog where you can set you own server links like your discord, your store or even your wiki! 

This plugin supports MiniMessage and it's Open Source so feel free to contribute if you want!
